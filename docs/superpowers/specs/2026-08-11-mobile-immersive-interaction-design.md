# 移动端沉浸交互与全景反馈优化设计

## 背景

当前展馆前端已经具备 krpano 全景浏览、场景切换、展品详情、图片缩放、音乐播放、全屏和模拟 VR 等能力，但存在以下体验问题：

- 移动端没有加载独立的方向传感器插件，无法通过转动手机改变全景视角。
- 移动端作品图片仍依赖桌面式的放大、缩小和重置按钮，不适合触屏浏览。
- 全屏只改变页面显示区域，没有尝试切换为横屏。
- 场景转场在新场景加载完成后才开始，且旧画面无法覆盖首次加载，慢速网络下会暴露黑色背景。
- 触屏设备暂停音乐后可能保留 `:hover` 视觉状态，按钮仍显示为金色。
- 前进热点和展品热点缺少足够明确的动态引导。
- 公安联网备案链接缺少备案图标和稳定的替换接口。

本设计在保留现有后端接口、展馆数据结构和桌面端主要交互的前提下，完善移动端沉浸体验，并为 PC 与移动端统一增强热点反馈。

## 设计目标

1. 恢复移动设备的陀螺仪浏览能力，并正确处理 iOS 权限限制。
2. 为移动端提供独立的顶层图片查看模式，支持双击、双指缩放和拖动。
3. 在全屏后尽可能自动进入横屏，不支持时安全降级。
4. 将场景加载与 1.5 秒叠化并行执行，避免额外等待和黑屏。
5. 让音乐按钮的视觉状态始终反映真实播放状态。
6. 为前进热点和展品热点增加可识别、不过度干扰的循环动效。
7. 在公安联网备案号前提供图标节点和可替换资源接口。

## 非目标

- 不修改点赞、评论、收藏、分享或登录接口。
- 不改变场景和热点 JSON 字段。
- 不将当前轻量前端壳替换为 `pano/` 中的旧前端应用。
- 不改变 PC 端现有图片放大、缩小和重置按钮。
- 不保证所有移动浏览器都能强制横屏；不支持时采用提示降级。

## 模块职责

### `krpano-adapter.js`

- 在动态场景 XML 中注册与当前播放器兼容的陀螺仪插件。
- 暴露陀螺仪可用性、启用、禁用和权限结果所需的适配接口。
- 根据热点 `type` 生成不同的 krpano 动效属性和动作。
- 将 krpano 的预览可见、场景加载完成事件桥接给页面协调层。
- 保持场景 generation 校验，过期场景事件不得结束当前转场。

### `museum-app.js`

- 管理每次页面生命周期内的一次陀螺仪权限申请。
- 在临时 UI 层打开时暂停传感器响应，关闭后恢复。
- 管理全屏请求、横屏锁定、退出解锁和兼容提示。
- 协调场景加载、启动遮罩和自适应交叉叠化。
- 根据 `<audio>` 的真实事件维护音乐按钮状态。

### `artwork-gallery.js`

- 保留桌面端当前缩放、拖动、键盘和多图切换行为。
- 增加移动端顶层查看状态及其触摸手势状态机。
- 在进入和退出顶层查看时保存、恢复作品详情滚动位置。
- 区分图片拖动、多图切换、单击退出和双击缩放。

### `index.html` 与 `museum.css`

- 增加顶层图片查看容器、关闭按钮和必要的可访问性属性。
- 增加横屏降级提示和首次加载视觉承载层。
- 对触屏与鼠标悬停样式进行分离。
- 在公安备案链接内增加独立图标节点。

### 静态资源

- 将 `pano/` 中与现有 krpano 运行时兼容的陀螺仪插件复制到 `/assets/krp/plugins/`。
- 将仓库中的 `img/beian_icon.png` 放入可由网站访问的备案资源目录。

## 移动端陀螺仪

### 权限与启用

- Android 等无需显式授权且支持方向传感器的浏览器，在播放器就绪后自动启用陀螺仪。
- iOS 上第一次触摸全景区域时，通过该用户手势调用 `DeviceOrientationEvent.requestPermission()`。
- 权限状态只保存在当前页面内存中，不写入 `localStorage` 或 Cookie。
- 同一次页面访问最多主动申请一次；刷新或重新进入网站后重新执行申请流程。
- 操作系统若已永久保存允许或拒绝，浏览器可以直接返回结果而不再次显示系统弹窗。

### 暂停与恢复

- 登录框、作品详情、展馆简介、场景抽屉或视角面板打开时暂停陀螺仪，避免背景视角误动。
- 上述临时层全部关闭后，仅在此前已授权且可用的情况下恢复。
- 权限拒绝、设备不支持或插件加载失败时只提示一次，手势拖动始终可用。

## 移动端作品图片查看器

### 入口和布局

- 移动端隐藏原有“放大、缩小、重置”工具栏；PC 端保持现状。
- 单击作品图片进入独立顶层查看层，查看层层级高于作品弹窗、评论输入框和其他页面控件。
- 顶层使用深色背景，图片按可用视口完整展示，并适配安全区域。
- 进入时保存作品详情当前滚动位置，退出后恢复，用户可继续向下查看说明和评论。

### 手势

- 双击在原始比例与预设放大比例之间切换。
- 双指连续缩放，缩放范围受最小和最大比例约束。
- 图片放大后可单指拖动，并限制位移，避免图片完全移出视口。
- 未放大时可横向滑动切换多张作品图片；已放大时横向拖动只移动图片。
- 原始比例下单击图片、单击背景或点击关闭按钮退出。
- 放大状态下单击图片不退出，防止观察细节时误关闭；仍可通过背景或关闭按钮退出。
- 单击判定需延迟到双击时间窗结束，第二次点击会取消单击退出，避免手势冲突。

### 状态清理

- 退出查看层、关闭作品弹窗或切换作品时重置缩放和位移。
- 图片加载失败时退出顶层状态，并复用现有错误提示。

## 全屏与横屏

- 点击全屏按钮后，先对 `museum-fullscreen-root` 请求全屏。
- 全屏成功后尝试调用 `screen.orientation.lock("landscape")`。
- 退出全屏时调用方向解锁，并恢复按钮的普通状态。
- 若方向锁定 API 不存在或调用失败，保持全屏可用并显示一次“请旋转手机横屏浏览”的轻量提示。
- iOS Safari 等限制强制横屏的浏览器采用上述降级，不将横屏失败当作全屏失败。

## 自适应场景交叉叠化

### 时序

叠化与新场景加载并行，而不是在加载完成后再增加固定等待：

1. 用户触发场景切换后立即冻结旧场景画面。
2. 同时向 krpano 发起新场景、低清预览和高清立方体贴图加载。
3. 旧画面立即开始缓慢淡出；新场景预览一旦可显示便同步淡入。
4. 若预览在目标时间内可见，整个交叉叠化约在 1.5 秒内完成。
5. 若网络更慢，旧画面淡出到最低保留透明度后暂停，直至新预览可见，再完成剩余交叉叠化。

这种方式让 1.5 秒同时承担视觉过渡和加载等待，不会在资源加载完成后额外等待 1.5 秒，也不会让旧画面完全消失后暴露黑色背景。

### 首次进入

- 首次进入没有旧画面可截图时，使用默认场景的低清预览作为启动遮罩。
- 启动遮罩持续到 krpano 已能显示预览，再平滑淡出。
- 加载提示可继续显示，但不以纯黑背景承载等待过程。

### 竞态与失败

- 每次切换沿用 generation 编号；只有当前 generation 的事件可以推进或结束转场。
- 连续切换时清理过期计时器、监听和遮罩状态。
- 新场景失败时撤销本次叠化并恢复旧画面，提示错误且不留下半透明遮罩。
- 开启“减少动态效果”时缩短为快速淡入淡出，但仍保留防黑屏承载逻辑。

## 热点动效

### 前进热点

- 继续使用现有前进热点图片。
- 通过 krpano 动作周期性改变 `scale`、`alpha` 和垂直偏移，形成向前上方推进的视觉节奏。
- 动画完成后回到初始值并循环，点击时立即收束反馈，然后执行场景切换。

### 展品热点

- 继续使用现有展品热点图片。
- 使用较小幅度的呼吸缩放和柔和透明度变化，突出其可点击性但不遮挡展品。
- 鼠标悬停或手指按下时增强一次反馈，打开作品弹窗后停止当前反馈。

### 可访问性与性能

- 动效直接作用于 krpano 热点，不创建遮挡点击区域的 HTML 元素。
- 动画参数按热点类型生成，未知和纯文字热点维持静态。
- 系统启用 `prefers-reduced-motion: reduce` 时不运行循环动画，仅保留静态热点与点击反馈。

## 音乐状态同步

- `play`、`pause`、`ended`、`error` 和音源变更都触发统一状态同步。
- 只有音频元素实际处于播放状态时，按钮才具有 `is-playing` 和金色视觉状态。
- 暂停、播放失败或结束后恢复普通灰白色。
- 将鼠标悬停样式限制在支持悬停的设备，避免触摸结束后残留金色 `:hover`。
- 切换场景时，如果音乐 URL 不变，不重置播放进度；只有 URL 确实改变时才更换音源。

## 公安联网备案图标

公安备案链接调整为图标与文字组成的同一链接：

```html
<a id="police-filing-link" href="https://www.beian.gov.cn/" target="_blank" rel="noopener noreferrer">
  <!-- 可将 src 替换为公安备案平台要求的正式图标地址。 -->
  <img id="police-filing-icon" class="police-filing-icon"
       src="/assets/filing/beian_icon.png" alt="" aria-hidden="true">
  <span>您的公安联网备案号</span>
</a>
```

- 使用稳定的 `id` 作为后续替换接口。
- 图标保持原始宽高比并与文字基线对齐。
- 图标加载失败时只隐藏图标，备案文字和链接仍可使用。
- ICP 备案链接保持不变。

## 异常降级

- 陀螺仪失败：保留手势拖动并提示一次。
- 横屏锁定失败：保留全屏并提示手动旋转。
- 新场景加载失败：恢复旧画面并清理转场状态。
- 顶层图片失败：退出查看层并显示图片错误提示。
- 自动播放被阻止：按钮保持暂停态，等待用户主动点击。
- 备案图标失败：隐藏图标，保留文字链接。

## 测试与验收

### 自动化测试

- 为陀螺仪权限状态、重复申请保护、暂停与恢复增加单元测试。
- 为叠化的正常加载、慢加载、首次进入、快速连续切换和失败恢复增加测试。
- 为音乐的播放、暂停、结束、失败和同 URL 场景切换增加状态测试。
- 为移动端图片查看器的打开、双击、双指缩放、拖动、单击退出、多图切换和状态清理增加测试。
- 更新静态前端检查，验证陀螺仪资源、顶层查看结构、横屏逻辑、热点动作和备案图标接口存在。
- 保留 PC 端图片工具、点赞、评论、收藏、分享、VR 和场景目录现有测试。

### 人工验收

- Android Chrome：自动陀螺仪、全屏横屏、图片双指缩放和叠化。
- iPhone Safari：每次页面进入后的权限申请、横屏提示降级、图片双击与双指手势。
- PC 浏览器：现有图片按钮与鼠标拖动不回归，热点动画和音乐状态正确。
- 普通动画与“减少动态效果”两种系统设置均可正常操作。
- 模拟慢速网络时，首次进入和场景切换期间不出现完整黑屏。

## 完成标准

1. 移动端授权后可通过转动设备浏览全景，刷新后会重新进入权限申请流程。
2. 移动端作品图片可进入顶层查看，完成双击、双指缩放、拖动和安全退出。
3. 全屏后优先横屏，不支持时有明确但不阻塞的提示。
4. 场景加载与约 1.5 秒交叉叠化并行，慢网下旧画面不会完全消失为黑屏。
5. 音乐按钮颜色与真实播放状态一致。
6. 前进和展品热点具有不同且可识别的动效，并支持减少动态效果。
7. 公安备案图标与文字共同组成链接，HTML 中保留稳定替换接口。
8. 自动化测试通过，PC 端已有功能无回归。
