# A-Frame 全景缩放设计

## 目标

为“境界AR”的 360° 全景查看器增加两种不依赖额外库的镜头缩放操作：电脑端鼠标滚轮和手机端双指捏合。单指拖动、设备陀螺仪、场景心跳、点赞和评论功能保持不变。

## 方案

场景创建后，从 A-Frame 默认相机取得 `camera` 对象，并通过修改其 `fov`（视场角）实现缩放。默认 FOV 为 80°；缩小 FOV 表示放大画面，增大 FOV 表示缩小画面。FOV 被限制在 35° 到 100°，防止过度放大造成明显失真或过度缩小影响浏览。

`aframe-host` 负责承载事件：

- `wheel`：滚轮向上减少 FOV，滚轮向下增加 FOV，并只在全景查看器内阻止默认页面滚动。
- `touchstart` / `touchmove` / `touchend`：仅双指手势参与缩放；依据两指间距离的变化调整 FOV。单指操作不拦截，继续交由 A-Frame 的 look-controls 处理转向。

每次打开场景创建一组专属监听器；关闭场景时移除监听器并清空状态。由此避免重进场景后同一手势被重复处理，或已关闭查看器继续响应输入。

## 验收与测试

- 静态页面集成测试检查相机缩放逻辑、`wheel` 和双指触摸监听存在。
- 手动验证：滚轮上/下分别放大/缩小；双指张开/合拢方向一致；FOV 始终处于 35°–100°；单指拖动仍可转向；退出后再次进入不会使缩放步长叠加。
- 不引入任何第三方依赖或后端 API 变更。
