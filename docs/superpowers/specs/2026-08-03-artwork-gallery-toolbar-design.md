# 展品画廊工具栏视觉调整设计

## 目标

将展品图片的“放大、缩小、重置”工具栏移动到图片区右下角，在三个按钮文字左侧增加与
展馆界面一致的金色线性 SVG 图标，并适当缩小按钮文字，减少工具栏对作品画面的遮挡。

## 结构

- 保留现有 `artwork-gallery-tools` 工具栏和三个按钮 ID，避免改变 `ArtworkGallery` 的事件
  接线与既有行为。
- 每个按钮内部增加一个仅用于装饰的内联 SVG：
  - 放大：放大镜与加号；
  - 缩小：放大镜与减号；
  - 重置：回转箭头。
- SVG 设置 `aria-hidden="true"`；按钮现有 `aria-label` 继续提供完整的可访问名称。
- 可见文字继续保留“放大、缩小、重置”，不使用图标替代文本。

## 布局与视觉

- 工具栏绝对定位在 `.artwork-gallery-stage` 的右下角，采用横向排列。
- 工具栏使用半透明深色背景、细金色边框和轻微圆角，使按钮在深浅作品上都清晰可见。
- 按钮采用图标在左、文字在右的紧凑排列；文字字号约 `0.78rem`，图标约 `15px`。
- 手机与短横屏继续位于图片区右下角，但缩小内边距、按钮间距和字号，避免遮挡作品主体。
- 不修改上一张、下一张、图片计数、缩放倍率、拖动和键盘交互。

## 测试与验收

- 静态集成测试检查三个按钮均包含内联 SVG，并保留中文文字和既有 ID。
- 静态样式检查工具栏使用右下角定位，按钮采用图文横向排列和更小字号。
- 运行全部前端 Node 测试与展馆静态页面测试，确认事件接线和现有画廊行为不回归。
- 浏览器人工检查桌面、390×844 竖屏及 844×390 横屏，确认工具栏不溢出图片区且按钮可点击。

## 非目标

- 不更改缩放、拖动、重置或多图切换逻辑。
- 不引入图标库、字体文件或外部依赖。
- 不修改后端接口、展馆配置、krpano 或数据库。
